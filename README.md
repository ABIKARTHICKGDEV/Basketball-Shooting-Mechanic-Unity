# 🎯 Features

- 🏀 Player movement
- 🤲 Ball dribbling animation
- 🎯 Hold-to-aim mechanic
- 🔄 Automatic player rotation
- 📈 Parabolic shooting trajectory
- ⚙️ Physics enabled after release
- 🔁 Ball reset and collection
